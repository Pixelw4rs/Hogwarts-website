Wie man beitritt

Java Edition

Füge www.ardet.de als Server in deiner Multiplayer-Liste hinzu. Whitelisted — bitte einen Admin, deinen Namen hinzuzufügen.

Bedrock Edition

Nutze einen GeyserMC-kompatiblen Client und verbinde dich mit www.ardet.de auf dem Port, den dir ein Admin gibt.
